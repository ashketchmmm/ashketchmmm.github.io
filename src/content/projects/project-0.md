For _thatgamejam #02_, a game jam on itch.io, I worked with a team to create _Star Monkey_, a game about a 
space monkey trying to return home. The game is an infinite runner with a swinging and boost mechanic, where 
the player traverses an endless forest. I was one of the Lead Programmers, developing the procedural generation 
scripts for the forest, assisting with UI design and implementation, and importing key assets and art.
