For my 6.2050 Digital Systems Laboratory class, my team and I created Spider Splayer: A FPGA Dungeon Crawler game using Verilog and an FPGA board. Below are some of the block diagrams and prototyping we utilized to create a first-person game that utilizes an IMU and the FPGA input buttons to determine attack and movement. My primary responsibiltiies were creating the spider rendering system, translating some of the raycasting modules, and writing the code provenance and final report.
